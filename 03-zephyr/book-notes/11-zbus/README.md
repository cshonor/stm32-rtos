## 本章讲什么

**ZBus 是 Zephyr 3.x 引入的发布-订阅消息总线：通道（channel）定义消息类型，
发布者 publish，订阅者（线程/监听器/消息队列三种形态）接收。**
它把 ch05 那些"点对点"IPC 升级成"多对多"——
一个传感器数据要同时喂给显示、记录、上报三个模块时，
用 msgq 得维护三条队列，用 ZBus 一个通道搞定。
