## 本章讲什么

**软件定时器 = "到点自动执行一个回调函数"的内核服务，全部定时器由同一个
后台守护任务（timer service task）统一处理。**本章回答：单次 vs 周期定时器、
定时器命令队列、以及为什么回调里**绝对不能阻塞**。

与裸机对照：[ch19](../../../stm32/book-notes/19-systick-and-timer/README.md) 里我们用
SysTick 手写"软件计数器到点翻标志"；软件定时器是同一思路的内核正式版——
但回调跑在**守护任务的上下文**里，不是 ISR，这个区别决定了能调什么 API。
