## 本章讲什么

**多任务共享资源（外设、全局变量、printf）时的保护手段全家桶：
临界区、挂起调度器、互斥量、守门人任务——以及 RTOS 教科书的头号反派：
优先级反转，和它的解药优先级继承。**

互斥量（mutex）和二值信号量长得像，但 mutex 多带了两样东西：
**所有权**（谁拿谁还）和**优先级继承**（防反转）。用信号量保护共享资源
是新手第一个结构性错误。
