# hardware/ —— 外设采购清单

> 一句话：**先别急着买。** 两块板（F103 = NUCLEO-F103RB，F407 = 正点原子探索者）的板载
> 资源加起来已经把常用外设覆盖了七成，这份清单只补剩下的三成。
>
> 判断口径是「仓库里哪个实验/轨道要用到它」，而不是「教程里出现过」。
> 用不上的东西买了就是吃灰。

## 0. 先看清楚：两块板已经自带什么

### NUCLEO-F103RB（`boards/f103rb.mk`）

| 自带 | 说明 |
|---|---|
| ST-Link/V2-1 | 板载调试器，**一根 USB 线搞定烧录 + 调试 + 串口**，不用买任何调试器 |
| 虚拟串口（VCP） | ST-Link 挂出来的 USART2（PA2/PA3），**UART 实验不用外接 USB 转串口** |
| 用户 LED | PA5（LD2），`03-gpio-blink` 用的就是它 |
| USER 按钮 | PC13，B13 引出（用户按键） |
| Arduino 排针 + 板边排针 | 所有 GPIO 都出来了，接模块靠它 |
| 3.3V / 5V / GND | 排针上都有，带载能力弱（总电流限制），大负载走 USB 单独供电 |

> F103 这块板**零外设也能把 04/05/06 三个实验全做完**。

### 正点原子 F407 探索者（`boards/f407zg.mk`）

板载资源（正点原子的板子基本把 F407 榨干了）：

| 类别 | 板载 | 对应总线 / 外设 |
|---|---|---|
| 存储 | W25Q128（16MB SPI Flash）、IS62WV51216（1MB 并口 SRAM）、板上 SD 卡座 | SPI / FSMC / SDMMC |
| 传感器 | MPU6050（六轴）、24C02 EEPROM、光敏、电容触摸键、红外接收头 + 遥控器 | I2C / ADC / EXTI / TIM 输入捕获 |
| 通信 | TJA1050（CAN）、SP3485（RS485）、SP3232 ×2（RS232）、RJ45 百兆以太网、2× USB OTG、NRF24L01 接口、蓝牙/GPS ATK 接口 | CAN / USART / ETH / USB / SPI |
| 单总线 | 1 路，支持 DS18B20 / DHT11 | 1-Wire（位操作练习） |
| 音频 | WM8978 编解码 + MIC + 耳机/喇叭输出 | I2S / I2C 控制 |
| 其他 | 有源蜂鸣器、DS0/DS1 LED（PF9/PF10，低电平点亮）、4 功能按键、RTC 后备电池座（有电池） | GPIO / RTC |

> 也就是说：**I2C、SPI、ADC、CAN、RS485、以太网、USB、单总线、音频、RTC——
> F407 一块板全带，不用额外买传感器。**

## 1. 必买（四个，别的都可以等）

| # | 买什么 | 型号 / 规格 | 参考价 | 为什么必须有 | 用在哪 |
|---|---|---|---|---|---|
| 1 | **杜邦线** | 公对公 + 公对母各 40 根（或一包混装） | ¥10–20 | 任何模块都要引出 3 根线，这是唯一的连接方式 | 全部 |
| 2 | **面包板** | 830 孔（半尺寸 400 孔也行） | ¥8–15 | 无焊接搭小电路 | 05/06、I2C 走线 |
| 3 | **ST-Link V2**（**克隆版即可**） | 淘宝「小蓝棒」+ 一根 SWD 4 线 / 杜邦排针 | ¥15–25 | **F407 探索者的调试器是排针外接的，没它烧不了 F407**。F103 不需要 | `boards/openocd/f407zg-stlink.cfg` 走这条路 |
| 4 | **逻辑分析仪** | 8 通道 24MHz SALA / Kingtwo 类 USB 型号 | ¥20–40 | 调试 I2C/SPI/UART 时序的唯一现实手段；接 PC 的 Sigrok / PulseView 直接看波形 | `04-uart-printf` 看 TXE 时序、后面 I2C/SPI 全靠它 |

> ⚠ **ST-Link 别买正点原子的原装**。仓库里 `boards/README.md` 写的就是克隆版 V2 的配置
> （`interface/stlink-v2.cfg`），买原装的反而要多配一层。

## 2. 想做项目再买（按需求选，一件一件加）

### 显示

| 买什么 | 型号 | 参考价 | 备注 |
|---|---|---|---|
| OLED 0.96" I2C | SSD1306，**I2C 版不是 SPI 版** | ¥10–18 | 两块板都能用（F103 的 I2C1 = PB6/PB7）。课程 Level 5「智能赛博小狗」显示输出基本靠它 |
| TFT 彩屏 | 1.8"/2.4" SPI（ILI9341/ST7789） | ¥25–45 | 只在 F407 上接（SPI1），做仪表/曲线才值得 |

> 两块板都**没有板载显示屏**（F407 只有 LCD 接口空座），所以屏幕是唯一「想看东西就必买」的。

### 传感器（能不买就不买，F407 板载已经很多）

| 买什么 | 型号 | 参考价 | 什么场景才买 |
|---|---|---|---|
| 温湿度 | SHT30 / AHT20（I2C） | ¥8–15 | DHT11 只有单总线且精度差，SHT 才有练 I2C 时序的价值 |

| 光照 | BH1750（I2C） | ¥6–10 | F407 有板载光敏，但那是 ADC 模拟量；BH1750 走 I2C 数字量，两条路都值得对比 |

## 3. 明确不用买的

| 别买 | 原因 |
|---|---|
| 正点原子 / ST 原版调试器 | `boards/openocd/*.cfg` 全是按 ST-Link 写的，克隆版够用 |
| 额外的开发板 | 已经有 F103 + F407 两块，一块 M3 一块 M4F，架构差异已经覆盖；再加只会摊薄精力 |
| 各种传感器大礼包套装 | 板载已经给齐，单买需要的 1–2 个即可 |
| 万用表（初期） | `tools/env.sh` + gdb 的 `mdw` 读寄存器能顶；真要量电压再买，¥30 的入门款足够 |
| 逻辑分析仪的**进阶款** | 8 通道 24MHz 就能抓 I2C/SPI/UART，100MHz 以上只在测 SPI 高频时才值 |

## 4. 按板子分工的建议

两块板不重复用，各干各的最省时间：

| 板 | 定位 | 主跑 |
|---|---|---|
| **F103 / NUCLEO** | 主机侧练**从零手写**——寄存器、启动文件、链接脚本都是自己写就看得见 | `00-toolchain-clang` / `01-bare-metal` / `03-gpio-blink` / `04-uart-printf` / `05-exti-button` / `06-timer`，以及后面所有裸机外设第一遍 |
| **F407 / 探索者** | 练**工程化**——外设多、板载全，注意力放在多总线协作、DMA、FPU、以及给 Linux 轨打硬件基础 | `02-freertos/*` / `03-zephyr/*`；硬件上直接玩 SD 卡、以太网、CAN、I2S、NRF24L01 |

> 这也解释了 `boards/` 为什么要分层：**同一份实验代码，`make BOARD=f103rb` 与
> `make BOARD=f407zg` 换的是编译目标和内存布局，不是两套代码。**

## 5. 最省钱的采购顺序

1. **先只买第 1 节四件**（≈¥55–100）。这四件到手就能把 `04/05/06` 三个实验做完，
   F103 全线打通，F407 也能烧录。
2. `04-uart-printf` 做完之后买 **OLED 0.96" I2C**（≈¥12），`03-gpio-blink` 之后买
   **无源蜂鸣器 + SG90 舵机**（≈¥12）——这两组一加，课程 Level 5「智能赛博小狗」
   的硬件就齐了。
3. 做 Level 6 紫外线项目时再买 **VEML6075**（≈¥15）+ **microSD 卡**（≈¥25）。
4. F103/F407 都通了、进 Zephyr 轨之后，才考虑 NRF24L01、彩屏、电机驱动这些。
