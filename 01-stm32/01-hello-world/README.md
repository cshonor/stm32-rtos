# 第 1 章 Hello World —— 章节导航

> 书：第 1 章 Hello World（原书 p3–15）
> 对应实验：`01-stm32/labs/00-toolchain-clang/`（Mac 上实测通过，产物 296 字节）

## 这一章在讲什么

**把 C 源码变成能在芯片上跑的字节，中间发生了什么。**

书用 PC 上的 hello world 当例子，讲的是"工具链"这件事本身：
先装编译器（1.1），再装 IDE（1.2），写出第一个程序（1.3），
用 make 固化流程（1.4），最后拆开看编译器内部（1.5）——**1.5 是全书最重要的一节之一**。

## 只看这一页（速览）

**主线一句话：** 本章回答"C 源码怎么变成能在芯片上跑的字节"——先解决工具链从哪来（1.1 装不装 GCC / 1.2 装不装 IDE），再写第一个程序验证编译链是通的（1.3），然后用 make 把命令固化、搞懂编译器标志（1.4），接着拆开"编译"看里面其实是四步（1.5，全章的枢纽），最后把 Makefile 从单文件扩展到多文件（1.6）。

| 小节 | 一句话结论 |
|---|---|
| [1.1](1.1-安装GCC.md) | 交叉编译看的是 target triple（ISA+OS+ABI）；GCC 把 triple 焊死在二进制里所以要单独下载，clang 一个二进制用 `--target` 现场切换 |
| [1.2](1.2-下载STM32系统工作台.md) | 书推荐的 SW4STM32 已停止维护；换成 clang + make + openocd 命令行三件套，全放家目录、免 sudo，还能按链路逐段排障 |
| [1.3](1.3-我们的第一个程序.md) | 裸机上没有 `printf`，"第一个程序"只能验证编译链通；报错分预处理/编译/汇编/链接/运行五层，"板子没反应"编译器一个字都不会说 |
| [1.4](1.4-改进程序和构建流程.md) | make 的核心是依赖图＋时间戳比较；`-Os` 在裸机上影响的是正确性（删空循环、断点打不上），调试期该用 `-Og`/`-O0` |
| [1.5](1.5-编译器在幕后的工作方式.md) | "编译"其实是预处理→编译→汇编→链接四步，只有第二步懂 C 语法；`.o` 里每个段地址都是 0，最终地址由链接器重定位填进去 |
| [1.6](1.6-在Makefile中添加内容.md) | 多文件 Makefile 靠 `wildcard`＋模式规则实现"新增 `.c` 零改动"；链接脚本必须写进依赖，否则改了不生效 |
| [1.7](1.7-总结.md) | 三句话收束：编译是四步、环境是按五段链路确认出来的、装 GCC/IDE 是手段不是目的 |
| [1.8](1.8-问题.md) | 原书习题正文缺失，换成六道本仓库实踩的自测题（`__aeabi_memcpy`、链接脚本依赖、`-Os` 断点等） |

**本章最容易踩的坑：**

- 漏把 `linker.ld` 写进 Makefile 依赖——改了链接脚本不重新链接，而且没有任何报错可看（1.4 / 1.6）
- 裸机上照书写 `printf("Hello World")`，编译能过、链接期才报 `undefined reference`（1.3）
- `-Os` 下非 `volatile` 的空循环被删成一条 `bx lr`、断点被内联跳过——调试期别用 `-Os`（1.4 / 1.8）
- `undefined reference to 'foo'` 不是 C 代码写错了，99% 是 `.o` 没参与链接或库顺序不对（1.5）
- 换编译器或改标志后没 `make clean`——增量编译不会因为 CFLAGS 变了而重编（1.4）

## 与书的差异（重要）

| 书 | 我 |
|---|---|
| 装 arm-none-eabi-gcc | 用 clang 23.1.0 + ld.lld（[理由](1.1-安装GCC.md)） |
| 装 System Workbench for STM32 | 不装。SW4STM32 **已停止维护**（[理由](1.2-下载STM32系统工作台.md)） |
| 第一个程序是 `printf("Hello World")` | 裸机上没有 printf。第 1 章的"第一个程序"只能验证**编译链通**，真正的输出在 [第 9 章串口](../09-uart-serial/README.md)（[9.5 串口 Hello World](../09-uart-serial/9.5-串口HelloWorld.md)） |
| 讲 PC 版 Makefile | 讲裸机版（多了链接脚本依赖、`.S` 规则、elf/bin 分离） |
