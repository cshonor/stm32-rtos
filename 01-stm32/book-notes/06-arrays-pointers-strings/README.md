# 第 6 章 数组、指针和字符串 —— 章节导航

> 书：第 6 章 数组、指针和字符串（原书 p78–88）
> 对应实验：主机侧 clang 23.1.0（含 `-fsanitize=address`）+ `--target=armv7m-none-eabi -ffreestanding` 交叉

## 这一章在讲什么

书按"数组 → 指针 → 算术 → 溢出 → 字符串"从用法讲到到底层。
但真正的心智模型是反过来的：**C 里只有指针，数组只是"连续的一块 + 一个名字"。**

对裸机来说这一章的分量比书里看上去重得多，因为：

1. **裸机通常不用堆**（[13.1 基本堆分配和释放](../13-dynamic-memory/13.1-基本堆分配和释放.md)），
   所有缓冲区都是**编译期定死的数组**——串口缓冲、采样序列、协议帧、显示缓冲；
2. **"指针"和"寄存器地址"是同一个东西**——
   理解了指针，就理解了 `*(volatile uint32_t *)0x40010800` 为什么长那样；
3. **数组越界在裸机上永远静默**——是所有 bug 里最难查的一类。

## 只看这一页（速览）

**主线一句话**：本章把"C 里数组名、指针、地址其实是同一个东西"这条线从头走到底——先弄清数组是什么、数组名何时退化成指针（6.1），再拆开指针的三要素：地址、类型、`volatile`（6.2），然后看两者混用时 `+1` 到底走多远（6.3），接着直面后果：越界在裸机上为什么永远静默、怎么防（6.4），最后落到字符串这个"只有约定没有类型"的最容易越界的特例（6.5）。

**每小节一句话结论**：

| 小节 | 一句话结论 |
|---|---|
| 6.1 数组 | 数组名在大多数表达式里退化成首元素地址，但 `sizeof(a)` 和 `&a` 不退化（实测 16 vs 8、步长 4 vs 16）；大缓冲必须 `static`/全局，只读表加 `const` 放 Flash |
| 6.2 底层细节：指针 | 指针 = 地址值 + 指向类型 + `volatile` 三要素，缺一不可；`*(volatile uint32_t *)0x40010800` 这串"咒语"每一截各管一件事 |
| 6.3 数组和指针算术 | `p+1` 前进 `sizeof(*p)` 字节而非 1，`p[i]` 就是 `*(p+i)`；"基址+偏移"必须用整数加法，指针口径差 4 倍 |
| 6.4 数组溢出 | 常量下标越界编译器能报 `-Warray-bounds`，运行时下标一声不响；裸机无 MMU 无 ASan 永远静默，防线必须前移到编译期和主机侧 |
| 6.5 字符和字符串 | C 没有字符串类型、只有 `\0` 约定；freestanding 没有 `<string.h>`，且编译器会偷偷生成 `__aeabi_memcpy` 调用，你不提供就链接失败 |

**本章最容易踩的坑**：

- "数组名就是指针"——实测 `sizeof(a)=16` vs `sizeof(p)=8`，两者类型根本不同（6.1）
- 数组传进函数后 `sizeof` 只得到指针宽度，长度信息丢失，必须额外传 `len`（6.1）
- 同一句 `base + 0x10`，base 是整数加 16 字节、是指针加 64 字节，混用即错（6.3）
- 运行时下标越界 `-Wall -Wextra` 完全无感，裸机上写坏数据无任何提示（6.4）
- `__aeabi_memset(s, n, c)` 参数顺序和标准 `memset(s, c, n)` **相反**，照抄签名内存会被填成长度值（6.5）

## 与书的差异（重要）

| 书 | 我 |
|---|---|
| 讲数组/指针的用法 | 每个结论配实测：`sizeof(a)=16` vs `sizeof(p)=8`、`a+1` 差 4 字节、`&a+1` 差 16 字节 |
| "越界是 UB" | 分三层实测：常量下标 clang 报 `-Warray-bounds`；**运行时下标一声不响**；ASan 才报 `stack-buffer-overflow` + 调用栈 |
| 讲字符串的 `\0` 约定 | 补上裸机特有的：写 Flash 静默无效、freestanding **没有 `<string.h>`**、编译器隐式生成 `__aeabi_memcpy` |
| 没提"数组该放哪" | 补上：`.bss` / `.data` / `.rodata` 的选择直接决定 20 KB RAM 够不够（实测段归属 `D`/`R`） |

## 读完本章你应该能回答

- `sizeof(a)` 和 `sizeof(p)` 为什么不同？`&a + 1` 和 `a + 1` 各走多远？（16 vs 4 字节）
- 传数组给函数为什么必须额外传长度？
- 常量下标越界和运行时下标越界，编译器反应有什么差别？（实测）
- 裸机上数组越界会踩到什么？（别的变量 / 返回地址 → HardFault）
- `char *s = "abc"` 和 `char s[] = "abc"` 在段归属和可写性上差在哪？（实测 `R` vs `D`）
- 为什么没写 `memcpy` 也会链接报 `undefined reference to __aeabi_memcpy`？
- `__aeabi_memset` 的参数顺序和标准 `memset` 有什么不同？
