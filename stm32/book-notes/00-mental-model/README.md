# 00 地基篇 —— 读全书之前必须先钉住的三件事

> 这一部分**不属于书里任何一章**。书第 1 章直接从"装 GCC"开始，
> 但那之前有三个前提没交代清楚，不钉住的话后面每一章都会缺一块地基。

## 三篇的顺序

| 篇 | 标题 | 一句话 |
|---|---|---|
| [00.01](00.01-没有OS的C语言.md) | 没有操作系统的 C 语言 | C 标准里没有"硬件"这个词，freestanding 只保证 7 个头 |
| [00.02](00.02-操作硬件的三个手段.md) | 操作硬件的三个手段 | 地址即寄存器（MMIO）、`volatile`、位运算 |
| [00.03](00.03-没有GCC行不行.md) | 没有 GCC 行不行 | 编译器只是实现，不是标准；clang + ld.lld 实测可用 |

## 为什么这三件事要先说

| 如果不知道 | 后面会在哪里卡住 |
|---|---|
| freestanding 的边界 | [1.03](../01-hello-world/1.03-我们的第一个程序.md) 第一个程序就用 `printf`，链接期才发现没有；[1.04](../01-hello-world/1.04-改进程序和构建流程.md) 不知道为什么加 `-ffreestanding -nostdlib` |
| MMIO / `volatile` / 位运算 | [第 3 章](../03-embedded-system-programming/README.md) 点灯代码看不懂为什么必须 `volatile`；[第 4 章](../04-numbers-and-bitops/README.md) 位操作整章失去落点 |
| 编译器只是实现 | [1.01](../01-hello-world/1.01-安装GCC.md) 会以为"必须先装 GCC"，在无 root 的 Mac 上平白卡住 |

## 一句话版（先记住这三句）

1. **裸机上，"标准库"不是不存在，而是变成了你的活。**
2. **C 碰硬件的三个手段：地址当寄存器用、`volatile` 告诉编译器别优化、位运算改单个位。**
3. **标准管语言，不管实现；`arm-none-eabi-gcc` 只是众多实现之一。**

## 读完这一部分你应该能回答

- `-ffreestanding` 和 `-nostdlib` 分别管什么？为什么两个都要加？
- `.data` 为什么"初值在 Flash、变量在 RAM"？
- `volatile` 保证什么？**不**保证什么？
- 为什么栈指针 SP 不用你设？
- 换掉 GCC 之后，哪些东西必须跟着改？
