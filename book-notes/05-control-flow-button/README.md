> （真机按键实验 `stm32/05-exti-button` ⬜ 待建；本篇所有读数类结论都标注了"未实测"）

## 这一章在讲什么

**C 的控制语句本身没什么可讲的，任何 C 书都有。这一章对裸机的价值集中在两点：**

1. **5.6–5.10「使用按钮」**——第一次从"输出"（点灯）转向"**输入**"（读引脚），
   第一次遇到纯硬件概念：**上拉/下拉电阻**，以及"**悬空 ≠ 低电平**"；
2. **5.14「反模式」**——两个在 PC 上只是"风格不好"、
   在裸机上会变成**循环消失/丢中断**的写法。本篇用反汇编把它们实锤了。

本章最重要的一个实测：**`while (flag == 0) { }` 在 `-Os` 下被编译成一条 `bx lr`——
等待循环整个消失。** 这是裸机新手最贵的一课。

## 与书的差异（重要）

| 书 | 我 |
|---|---|
| 用下拉电路（按下读到 1） | 说明**上拉电路按下读到 0**，并强调"看原理图，别猜"（Nucleo 板待实测） |
| 去抖用忙等 `delay_ms(20)` | 不给它背书：实测空循环在 `-O2/-Os` 下**被整个删掉**，改用定时采样状态机 |
| 反模式当风格问题讲 | 用反汇编实锤：**`wait_bad` → `bx lr`**、`-Wparentheses` 加括号就失效 |
| 讲 `if` / `for` 语法 | 实测四种 `if` 写法机器码相同、`for` 与 `while` 机器码相同——**别为效率改写法** |
| 没讲 `goto` | 补上：`goto` 向前跳做清理/退出多层循环是**正当**用法（Linux 内核风格） |

## 读完本章你应该能回答

- 为什么 `while (flag == 0) { }` 会被编译成 `bx lr`？加什么能修？（`volatile`）
- 空 `for` 循环在 `-O0` / `-O2` / `-Os` 下分别有多少条指令？（22 / 1 / 1）
- 读按键前要配哪三件事？顺序错了会怎样？（时钟 → 模式 → 上/下拉；错 = 静默失效）
- 上拉和下拉，按下分别读到什么？F1 上"选上/下拉"靠哪个寄存器？（`ODR` 位兼任）
- 一次机械按下为什么会被读成好几次？三种去抖方案哪个该用？
- ISR 里的 `break` 为什么可能让程序"死掉"？（跳过清中断标志）
- `for` 和 `while` 哪个快？（实测：一样）
