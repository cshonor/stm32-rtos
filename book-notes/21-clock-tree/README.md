## 为什么书里没有这一篇

书里从第 1 章到第 18 章，所有程序都跑在**上电默认时钟**上：
F030 是 HSI 8 MHz，本仓库的 F103 也是 HSI 8 MHz。
点灯、按键、中断——8 MHz 全都够用，所以书不提时钟树也顺理成章。

但只要往前走一步，时钟树就绕不开：

| 需求 | 为什么默认时钟不够 |
|---|---|
| UART 115200 波特率 | 8 MHz 分出来的误差偏大，串口乱码（02-libopencm3 明说"波特率算错就看不到串口输出"） |
| USB | **必须** 48 MHz，只能从 PLL 出 |
| SysTick/TIM 定时精度 | 19.1 那个"延时差 9 倍"的坑，根源就是 8 MHz vs 72 MHz |
| RTOS 系统吞吐 | 主频 ×9，同样时间能干的活 ×9 |

"8 MHz 晶振为什么能跑出 72 MHz"——答案是 PLL（锁相环倍频）。
这是裸机工程师的第一堂"模拟数字混合"课，书里没写，这里补。

## 这一篇在讲什么

**时钟从晶振/RC 振荡器出发，怎么一路分到 CPU 和每个外设。**

```
时钟树全景：HSI/HSE → PLL → SYSCLK → AHB/APB（21.1）
   → 为什么每个外设用之前都要先"开时钟"（21.2）
```
