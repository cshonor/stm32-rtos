## 本章讲什么

**空闲任务反正都在跑，不如让它干点正事：把 MCU 睡下去。**
本章讲 tickless idle——空闲任务算出"下一个定时事件还有 N 个 tick"，
就把 SysTick 停掉、MCU 进低功耗模式睡 N tick，省下周期性唤醒的电量。
