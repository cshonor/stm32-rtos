# 10.1 空闲钩子睡法（简单版）vs tickless idle（正式版）

## 这一篇讲什么

所有任务都阻塞时，CPU 上只剩空闲任务在跑（见
[3.5 空闲任务与钩子](../03-task-management/3.5-空闲任务与钩子.md)）。
电池设备上，这段"空转"时间应该拿来睡觉。本章两条路：
**空闲钩子里手动 WFI（简单版）** 和 **tickless idle（正式版）**。
本篇先讲简单版的做法与天花板，再说正式版要解决的问题。

## 简单版：空闲钩子里 WFI

```c
/* FreeRTOSConfig.h: configUSE_IDLE_HOOK 置 1 */
void vApplicationIdleHook( void )
{
    __WFI();   /* Wait For Interrupt：睡到下一个中断 */
}
```

空闲任务每次循环都执行一条 WFI，CPU 时钟停振，任何中断都能叫醒。
改动极小，立刻见效。

**但它的天花板很明显**：SysTick 心跳还在走。
`configTICK_RATE_HZ = 1000` 时，**每 1ms 就来一次 tick 中断**，
CPU 刚睡下去就被自己的心跳叫醒——

```
时间轴（1ms tick）:
|睡|醒(tick)|睡|醒(tick)|睡|醒(tick)| ...  ← 每次"睡"不足 1ms
```

睡-醒切换本身也耗电（时钟稳定、上下文进出），
1ms 粒度下省电效果大打折扣。对电池设备，
"每小时被闹钟叫醒 360 万次"就是灾难。

## 正式版：tickless idle 的思路

问题根源：tick 中断是**周期性**的，但下一个"真正有事"的时刻
往往很远。tickless 的思路一句话：

> **既然算出未来 N 个 tick 都没事干，就把周期 tick 停掉，
> 把唤醒源一次性编程到 N tick 之后，连续睡 N tick。**

```
tickless 时间轴:
|←──────── 连续睡 N tick ────────→|醒(定时事件到点)
        中间没有周期性唤醒
```

前提：内核知道"下一个定时事件在 N tick 后"——
这信息内核本来就有（各任务的阻塞超时、软件定时器的到期时间
都挂在定时名单上），空闲任务跑起来时取最近的一个到期时刻即可。

## 两种睡法对照

| | 空闲钩子 + WFI | tickless idle |
|---|---|---|
| 改动量 | 一个钩子函数 | 开 config + port 层支持 |
| 单次睡眠上限 | < 1 个 tick | N 个 tick（N 可达数千） |
| 周期 tick | 照走，照样打断睡眠 | 睡眠期间停掉 |
| 醒后 tick 计数 | 天然正确（每次 tick 都醒过） | 要**补偿**（vTaskStepTick，下篇讲） |
| 适用 | 插电设备顺手省电 | 电池设备的正式方案 |

## 开启条件

```c
/* FreeRTOSConfig.h */
#define configUSE_TICKLESS_IDLE    1
```

开了之后，空闲任务的决策权交给 port 层的
`portSUPPRESS_TICKS_AND_SLEEP()` 宏：内核在空闲时调用它，
由它完成"算睡眠时长 → 停 tick → 睡 → 醒后补 tick"全流程。
Cortex-M 官方 port 自带参考实现（弱符号，可覆写），
F103 上可以直接用或改造成睡 Stop 模式——
具体分两步在下两篇拆。

## 要点回顾

1. 空闲钩子 + WFI 是最小省电改动，但被周期 tick 切成碎觉。
2. tickless 的核心：预知空闲 N tick → 停 tick → 一次性睡 N tick。
3. 开关是 `configUSE_TICKLESS_IDLE`，干活的是 `portSUPPRESS_TICKS_AND_SLEEP`。

<details>
<summary>Q1：空闲钩子里只写 WFI，有副作用吗？</summary>

注意两点：一是钩子函数**不能阻塞**（空闲任务被挂起会导致
"已删除任务的 TCB 没人回收"等内务停摆）；二是 WFI 之后
CPU 醒来的第一个中断可能就是 tick——省电收益小但无害，
插电设备上可以无脑开。

</details>

<details>
<summary>Q2：tick 停了，vTaskDelay 还准吗？</summary>

准——这正是"醒后补 tick"存在的意义。醒来时内核根据
"实际睡了多久"把 tick 计数一次性补齐，被延时阻塞的任务
看到的逻辑时间和没睡一样。补不准的场景（非定时唤醒）
下篇讲 vTaskStepTick 时细说。

</details>
