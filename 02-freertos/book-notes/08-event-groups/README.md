## 本章讲什么

**事件组 = 一个 24 位的"事件标志字"，任务可以按"任意位置位"（OR）或
"全部置位"（AND）两种条件阻塞等待。**它解决的是"一个任务要等好几件事
都发生/任意发生"的场景——用 N 个信号量做不到，用一个队列语义不对。
