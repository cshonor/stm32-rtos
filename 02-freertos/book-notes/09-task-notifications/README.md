## 本章讲什么

**任务通知 = "直接发给某个任务的轻量事件"，每个任务自带一个 32 位通知值，
不需要单独创建队列/信号量对象。**官方定位：在"一对一"场景下，
任务通知可以替代二值信号量、计数信号量、事件组、甚至长度 1 的队列——
**快约 45%、RAM 更省**（书里的实测口径）。

代价是限制：只能一对一（ISR→任务 或 任务→任务），不能一对多；
只有接收方能阻塞（发送方不能等"对方收走"）。
