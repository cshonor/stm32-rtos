## 本章讲什么

**FreeRTOS 留给开发者的"自检与观测"工具箱：configASSERT、栈溢出检测的
两种方法、运行时统计（每个任务吃了多少 CPU）、trace 钩子宏。**
这一章是"调试期保命手册"——不出事时用不上，出事了全是它。
